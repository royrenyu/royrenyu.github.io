# 狼人杀项目修复说明

**日期：** 2026-11-27  
**基线：** `b0aa80f252da0479d243f1ba2c99760f083221e4`

## 修复内容

### 游戏规则与状态

- 同一玩家同夜受到多种伤害时，保留全部死因。
- 猎人同夜被刀、被毒时不再错误触发开枪。
- 夜间死亡统一批量结算，所有死亡及连锁技能处理完后再判断胜负。
- 猎人、狼王待结算技能存在时，胜负会延后到技能处理完毕。
- 胜利成为终态，不能继续下一夜、投票或修改行动。
- 白狼王自爆后重新结算胜负，不再清空胜利并继续游戏。
- 已结算的天亮与放逐阶段禁止倒退修改。

### 投票

- 票型记录投票人和目标，不再只保存目标票数。
- 禁止死者投票、无票权玩家投票、同一玩家重复投票和投给已出局目标。
- 白痴失去投票权后仍可正常参与发言。
- 平票增加“PK 重投”和“无人出局”两个明确流程。
- 平票点“下一步”不会绕过结算直接进入下一夜。

### 自定义板子

- 总人数校验计入自定义身份数量，超员配置不能开局。
- 同一自定义身份多人时，每人拥有独立夜间步骤和目标记录。
- 机械狼学习自定义身份时不再因缺少预设技能而报错，交由主持人按现场规则处理。

### 在线房间

- 身份不再以明文 `ids` 存在公共云存储。
- 每个玩家设备生成 ECDH 密钥对，上帝端按座位公钥分别加密身份。
- 玩家只在本地解密自己的身份。
- 房间写入加入版本号、写后校验、冲突重试和延迟复核。
- 同一设备不能同时占用多个座位。
- “解散房间”会删除远端数据；不支持删除时会写入失效标记。
- 旧版本房间需解锁后重新选号，以生成新的设备公钥。

### 工程与发布

- `index.html` 成为 Git 中的唯一源码，不再从外部豆包页面自动抓取覆盖。
- GitHub Actions 改为只读校验，不再自动写回 `main`。
- Actions 固定到具体提交 SHA。
- 新增状态结构校验和异常存档备份。
- 自定义身份名称输出增加 HTML 转义。
- 新增静态检查和规则回归测试。

## 升级提示

1. 旧在线房间必须先“解锁重选”。
2. 玩家需要在自己设备上重新选号。
3. 玩家清除浏览器站点数据后，需要上帝解锁并重新发牌。
4. 第三方公共存储没有服务端鉴权和原子事务；高价值正式局仍建议换独立后端。
