## 说明
- 页面是静态控制台，选号房间数据走公共临时云存储，需要联网。
- `index.html` 已纳入 Git，是唯一源码版本；不再从第三方页面自动覆盖。
- 玩家身份使用每个设备的公钥单独加密；房间 ID 只能读到密文，不能直接看到全量身份。
- 规则测试由 GitHub Actions 在推送和 PR 时自动运行。
- 上方使用说明图保留为本地静态资源。
## 常见问题
- 玩家点链接显示「连不上房间」：先看提示里的原因。显示「房间不存在（可能已过期）」说明这个链接对应的房间在读不到，让上帝在「在线选号」里点「检查链接」，必要时点「重建房间」换新链接重新发群；显示「网络超时」只是手机网络慢，页面会自动重试，不用退出。
